# Metraza UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-optimized:subagent-driven-development (recommended) or superpowers-optimized:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve the Metraza Android Compose UI into a compact, precise industrial calculator while preserving the existing calculation and validation behavior.
**Architecture:** Keep business logic in `app/src/main/java/com/metraza/data/` unchanged. Apply the UI polish through the existing Compose theme, component layer, and `CalculatorScreen` only. Use UI tests for observable structure, accessibility semantics, and result layout; use Gradle build/lint as the visual-code safety net.
**Tech Stack:** Kotlin, Android Gradle Plugin 8.7.3, Jetpack Compose Material 3, Compose UI test, Android instrumentation tests.
**Assumptions:**
- Assumes this is a UI-only pass — will NOT work as a calculation, density, validation, sharing, or persistence change.
- Assumes dark theme remains the only theme — will NOT add light mode.
- Assumes the existing `logo.png` and `space_grotesk_wght.ttf` assets stay — will NOT replace brand assets.
- Assumes Android instrumentation can be run on an emulator/device for UI tests — local unit tests alone will NOT prove Compose UI semantics.
- Assumes project Git commands remain out of scope unless the user explicitly asks — this plan intentionally omits commit steps.

---

## File Structure

- `app/build.gradle.kts` — add instrumentation runner, Compose UI test dependencies, and Material Icons dependency for status icons.
- `app/src/androidTest/java/com/metraza/ui/CalculatorScreenTest.kt` — replace stale tests with current baseline tests and add tests for new UI semantics.
- `app/src/main/java/com/metraza/ui/theme/Theme.kt` — wire the bundled Space Grotesk font, app shapes, and refined typography.
- `app/src/main/java/com/metraza/ui/theme/AppConstants.kt` — refine surface/color tokens and layout tokens without changing material data.
- `app/src/main/java/com/metraza/ui/components/LabeledTextField.kt` — add suffix units, supporting text slot, and test tags.
- `app/src/main/java/com/metraza/ui/components/MaterialGridSelector.kt` — make material chips selectable controls with clearer selected state.
- `app/src/main/java/com/metraza/ui/components/Buttons.kt` — support optional button icon content while keeping existing button call sites compatible.
- `app/src/main/java/com/metraza/ui/components/GlassCard.kt` — reduce over-glass styling and align card radii/elevation with the theme.
- `app/src/main/java/com/metraza/ui/screens/CalculatorScreen.kt` — compact the header, add sticky keyboard action, add status icons, and replace result rows with a stable metric layout.
